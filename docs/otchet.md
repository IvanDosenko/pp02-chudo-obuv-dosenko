# Отчет по производственной практике (ПП.02)

**Тема:** Разработка и интеграция информационной системы «Чудо Обувь» средствами Python и СУБД PostgreSQL.
**Студент:** Даценко Иван
**Группа:** 3ИП-13-24

## 1. Цель работы
Освоить полный цикл разработки приложения: от проектирования реляционной базы данных до создания кроссплатформенного пользовательского интерфейса с ролевой моделью доступа.

## 2. Выполненные задачи
В ходе практики были реализованы следующие модули:
1. **База данных (PostgreSQL):** Создана структура из 7 таблиц с внешними ключами, ограничениями (CHECK, NOT NULL) и каскадным удалением.
2. **Каталог товаров:** Реализован вывод карточек с изображениями (и заглушками). Настроен автоматический расчет скидки 25% для товаров без заказов за последний месяц. Реализована подсветка красным цветом при остатке ≤ 3 пар.
3. **Авторизация и фильтрация:** Реализован вход по логину (без пароля). В каталог добавлены поиск, фильтрация по категориям и сортировка по цене, работающие в реальном времени.
4. **Оформление заказа (Корзина):** Реализовано добавление товаров с выбором размера и количества. Оформление заказа происходит через транзакцию с проверкой остатков на складе.
5. **Управление заказами:** Создана вкладка для менеджеров и администраторов. Реализован просмотр состава, удаление заказов. Администратор может изменять дату и удалять отдельные позиции.
6. **Обработка ошибок:** Все критические операции обернуты в блоки `try...except` с выводом диалоговых окон (`QMessageBox`).

## 3. Выводы
В результате практики было разработано полнофункциональное десктопное приложение, отвечающее всем требованиям технического задания. Освоены навыки работы с PyQt5, PostgreSQL и psycopg2, а также проектирования баз данных и обеспечения безопасности транзакций.
