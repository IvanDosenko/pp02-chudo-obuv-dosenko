# Чудо Обувь: Менеджер заказов

Десктопное приложение для автоматизации заказов торговой компании «Чудо Обувь». 
Стек: Python 3.10+, PostgreSQL, PyQt5.

## Инструкция по развертыванию

1. Установите PostgreSQL и создайте базу данных пользователя `postgres`.
2. Клонируйте репозиторий:
   `git clone https://github.com/IvanDosenko/pp02-chudo-obuv-dosenko.git`
3. Установите зависимости:
   `pip install -r requirements.txt`
4. В файле `src/db_utils.py` и `src/db_init.py` укажите ваш пароль от PostgreSQL в переменной `password`.
5. Инициализируйте базу данных:
   `python src/db_init.py`
6. Запустите приложение:
   `python -m src.main`
